# Wan2GP-podman
Contained only modified files from Wan2GP repository suitable for use with Podman to build and run container.
Note that the files are not finalized version, feel free to modify on your own to fit your use.

One more thing, I am using an old laptop with RTX 2070 GPU / 8GB VRAM, so I fixed the command line in run-docker-cuda-deb.sh for testing. Please remove the podman command line and uncomment the original command line to evaluate performance of your computer.
